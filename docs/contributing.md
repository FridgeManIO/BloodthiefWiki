# Contributing to the wiki

Thank you for considering contributing to the wikidocs. Any and all contributions are welcome, no matter how large or small. All contributors wil be credited on this page. 

## Requirements
- Ensure any changes you push do not break the build. At least attempt to build the docs locally with `mkdocs build`, and inspect any error messages/info carefully.
- Keep your changes in line with the general style of the wiki.
- Try to keep file sizes low, especially images. No 4k screenshots please.
- No low-effort or significantly AI-generated content appreciated.

## How to Contribute

### Open up a pull-request on github
- Create github account.
- Fork [this repo](https://github.com/FridgeManIO/BloodthiefWiki).
- Make changes and test locally.
- Open pull request if everything looks good.

### DM me on discord
If you feel like github is a bit much to learn to contribute to a wiki (and it would be for a lot of people), feel free to join the [blargville server](https://discord.gg/aU5naj2fgY) and either drop a message in one of the server chats, or DM me at "ManjaroKDE/ArchHyprlandBTW" (I use arch btw). 

I'll accept partially formatted submissions for things like lore dumps, item notes, etc, but you should edit them in a markdown editor such as [stackedit](https://stackedit.io/app#). 

If you're proposing changes to a file, and not a new file entirely, download the source file from the github and send the whole thing with your changes added.

### Open Issues
Don't feel like directly contributing but feel like something is not quite right? Either open a new issue on the [github repo](https://github.com/FridgeManIO/BloodthiefWiki), or message me on Discord.
