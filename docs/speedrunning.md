# Speedrunning

## Useful Resources

* [Bloodthief Speedrunning Discord](https://discord.gg/FfpX2GEurg) - The #1 spot for any questions or discussions. Includes a [table of contents](https://discord.com/channels/1187488021176664115/1188648824890195988) for typical speedrunning terms.

* [Bloodthief Data by Gribovar](https://docs.google.com/spreadsheets/d/1HdAnAZaL4W4uIpMkvH7w3az-70uQCw1-ZU3z57yp8dk/edit?gid=0#gid=0) - Spreadsheet including GK times, artifacts list, lore notes, etc

* [Bloodthief Speedrun Guide by Gribovar](https://www.youtube.com/watch?v=IACPAA_7eD8) - Video made for the demo showing most speedrun tech.

* [Bloodthief Speedrun.com Leaderboards](https://www.speedrun.com/Bloodthief)

* [Autosplitter Source Code (Windows) by Micrologist](https://github.com/Micrologist/LiveSplit.Bloodthief/blob/main/BloodthiefDemo.asl) - Install the autosplitter via [Livesplit](https://livesplit.org/)

* [Autosplitter for Linux by Olvior](https://github.com/olvior/bloodthief-wasm-autosplitter) - Scroll down and follow the instructions in the "Usage" section to install.

* [Bloodthief Style OBS Input Overlay by otiks55](https://www.speedrun.com/Bloodthief/resources/unryd) - Fancy input overlay for your Bloodthief recordings. [Setup tutorial by Frogman](https://www.youtube.com/watch?v=Xlz3vUWY3zg)

* [TAS mod by Emma](https://github.com/Luna5829/bloodthief-tas-mod) - Bloodthief TAS mod. Please refer to the [modding section](modding.md) for further info. Note that leaderboard entries will be automatically disabled while mods are enabled.
