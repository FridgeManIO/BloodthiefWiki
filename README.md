# Guide

To install the dependencies follow the guide on [material mkdocs](https://squidfunk.github.io/mkdocs-material/getting-started/).

To build the site from source, run `mkdocs serve` for a liveserver, or `mkdocs build` for a one-time build.

If mkdocs serve doesn't work, you can either use the either the live-server vscode plugin, or run `npx live-server site/`.

Website builds and deploys automatically at (https://bloodthiefwikidocs.pages.dev/).
